# Selection Sort
ตัวอย่าง
[5, 4, 3, 2, 1]
1. เลือกตัวเลขจากปลายแถว [5, 4, 3, 2, **1**]
2. หาตัวเลขที่มากที่สุดของตัวเลขที่เหลือ [**5, 4, 3, 2**, 1]
3. จากข้อ 1. ได้เลข **1** และจากข้อ 2. ได้เลข **5** นำมาเปรียบเทียบกัน
4. ถ้า จากข้อ 2. มากกว่า จากข้อ 1. สลับ [**1**, 4, 3, 2, **5**]
5. ซ้ำข้อ 1. - 4. ไปเรื่อยๆ จนครบทุกตัว
